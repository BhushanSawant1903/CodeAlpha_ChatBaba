# CHAT BABA — CodeAlpha Python Internship

## Project Overview
CHAT BABA is a beginner-friendly, rule-based chatbot developed using Python as part of the CodeAlpha Python Programming Internship.

The chatbot interacts with users through the terminal and responds to predefined commands using conditional statements and randomized replies.

## Features
- Recognizes greetings such as hello and hi
- Responds to questions such as "How are you?"
- Introduces itself when asked its name
- Responds to thank-you messages
- Provides a help menu showing available commands
- Uses randomized responses for more natural conversations
- Handles unrecognized messages
- Allows users to exit using the bye command

## Technologies Used
- Python 3
- Built-in `random` module

## Python Concepts Used
- Variables and strings
- `if-elif-else` statements
- `while` and `for` loops
- Lists
- String methods such as `.lower()`, `.strip()`, and `.split()`
- `random.choice()`
- `any()` function

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project directory.
4. Run the chatbot using:

   `python "Chat_BABA.py"`

5. Type messages to interact with CHAT BABA.
6. Enter `help` to see available commands.
7. Enter `bye` to exit.

**Note:** Replace `Chat_BABA.py` with the actual filename of your Python program.

  User: hello
